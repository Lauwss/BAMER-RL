## 结论

1. **训练侧开启全额兑现 +31pp（60→91%）**：与评估侧 A/B 的 90-92% 天花板一致
   ——训练侧修复不但成立，且没有任何折损；机制假设（训练期 ε 采到
   ImageFeed→Pickup 转移、补上盲区格的学习信号）成立；
2. **截断率 9% 与 e0dbb35 注记对上**："剩余 ~9% = 扫掠未完成的真预算问题"
   ——盲区修复后，失败余量回到纯粹的探索效率/预算问题（探索率 68.5%、
   墙知识 85.5% 即为效率画像）；
3. **POI 定位率（93%）首次高于成功率（91%）**：出现 2 个"定位成功但派送未
   完成"——此前所有批次定位率=成功率（派送段零失败），修复后派送段第一次
   成为尾段小瓶颈（预算相关，量级 2%可忽略但不为零）；
4. 训练期 + 评估期一致开启（同掩码语义）为**当前最优口径**：91% 是全项目
   held-out 最高读数。
