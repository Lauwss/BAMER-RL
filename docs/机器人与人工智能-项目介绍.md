# 《机器人与人工智能》项目介绍

> 基于 PPT《机器人与人工智能》整理 · 共 6 部分

## 一、项目概述

本项目以**智能机器鼠（Micromouse 式）迷宫探索与目标派送**为任务载体，将人工智能的多项核心技术融合于一个完整的仿真系统：

- **深度学习图像识别**：识别迷宫中遇到的屈原/昭君古装图像；
- **强化学习 + 搜索算法 + 路径规划**：让机器鼠自主探索迷宫，并使"搜寻 + 派送"的时间（距离/步数）最优；
- **机器人感知仿真**：激光雷达点云、摄像头视觉反馈，在 ROS/Gazebo、Unity 或 Matlab 等环境中动态呈现。

机器鼠需要像真实机器人一样，在**不知道地图结构、不知道目标位置**的前提下，依靠自身传感器完成从"探索"到"识别"再到"派送"的全流程闭环。

## 二、任务场景

场景为一个 **16×16 的迷宫地图**（坐标 0~15）：

| 要素 | 说明 |
| --- | --- |
| 机器鼠 | 从起点 (0,0) 出发，自主探索迷宫 |
| 屈原状态机 | 随机分布在地图点位上，被经过时向机器鼠反馈屈原古装图片 |
| 昭君状态机 | 随机分布在地图点位上，被经过时向机器鼠反馈昭君古装图片 |
| 目的地：楚国 | 坐标 (8,8)，识别为"屈原"后的派送终点 |
| 目的地：西汉 | 坐标 (7,7)，识别为"昭君"后的派送终点 |

状态机与机器鼠之间形成双向交互：机器鼠**实时上报自身位置坐标**给状态机；机器鼠经过状态机所在位置时，状态机**下发对应人物（屈原/昭君）的古装图片**。

## 三、系统组成与工作流程

### 1. 场景与地图构建
- 构建 16×16 迷宫地图，包含墙壁、通道与坐标网格；
- 地图中随机布置 2 个状态机（屈原、昭君），位置可变。

### 2. 图像数据集与识别模型
- **数据集构建**：搜集或利用 AI 生成屈原/昭君古装图像，分别构建 2 个数据集；
- **模型训练**：通过深度学习训练图像分类模型；
- **在线识别**：机器鼠接收到状态机反馈的图像后进行识别，依据识别结果决定派送目的地——
  - 识别为"屈原" → 派送至**楚国 (8,8)**
  - 识别为"昭君" → 派送至**西汉 (7,7)**

### 3. 机器鼠本体
**传感器配置：**
1. **激光雷达**——需呈现点云变化（环境感知）；
2. **摄像头**——需呈现识别到的昭君/屈子图像（视觉识别）。

**运动模型约定：**
- 直行与旋转均忽略加减速过程，视为匀速运动；
- 但旋转需计入最终的 step（步数）统计。

**核心功能：**
1. 搜寻屈原/昭君所在位置，并将其"派送"至对应目的地；
2. 通过 **强化学习 + 搜索算法 + 路径规划**，使机器鼠"搜寻 + 派送"的时间（距离或步数）最优。

### 4. 仿真工具（推荐，任选其一）
1. **ROS + Gazebo + Rviz**
2. **Unity**
3. **Matlab**

### 5. 成果呈现要求
1. 动态呈现每一次机器鼠探索路径的过程；
2. 实时展示机器鼠运动的步数；
3. 实时显示激光雷达点云；
4. 遇到状态机时，展示当前识别的图像；
5. 在展示无数条探索路径之后，最终给出**最优路线**；
6. 最后以**录屏 + 演讲**的形式汇报。

## 四、关键规则与约束

- **信息封闭**：地图结构、状态机位置**不允许直接告诉机器鼠**，必须由机器鼠自己探索获得；
- **代码冻结**：代码中预留状态机位置输入接口，但**开始测试后不允许再修改代码**；
- **评价标准**：以"搜寻 + 派送"的时间（距离或步数）最优为核心指标。

## 五、技术要点提炼

| 技术方向 | 在本项目中的作用 |
| --- | --- |
| 深度学习 / 图像分类 | 构建屈原/昭君数据集并训练识别模型 |
| 强化学习 | 机器鼠在未知迷宫中学习探索与派送策略 |
| 搜索算法 / 路径规划 | 求解最优路线，最小化步数/距离 |
| 激光雷达 / 点云 | 迷宫环境感知与建图 |
| 状态机交互 | 位置上报 + 图像反馈的任务触发机制 |
| 机器人仿真 | ROS+Gazebo+Rviz / Unity / Matlab 三选一 |

## 六、项目意义

本项目将经典 Micromouse 迷宫竞速问题与传统文化元素（屈原、昭君）相结合，把**感知（点云）、认知（图像识别）、决策（强化学习与路径规划）、执行（运动控制）**四大机器人能力串联为一条完整的任务链，是一个贴近真实机器人开发流程、可仿真、可展示、可量化的综合性人工智能实践项目。
