## 0. 设计总览

**任务**：机器鼠在 16×16 迷宫中，不被告知地图与状态机/终点位置，自主探索找到屈原/昭君状态机，识别后派送至楚国/西汉，"搜寻 + 派送"总步数（含转向）最优。

**算法一句话**：分层选项式（SMDP）Dueling DQN——高层策略在 option 边界输出符号动作 `{Explore(目标点) / Pick(标签) / Deliver}`，底层执行器用 (格,朝向) 状态空间 BFS 确定性执行；智能体输入为由账本派生的 16 通道全图信念张量。

```
                 ┌────────────── 算法侧（R1 合规：只吃量测/事件/自身信息）──────────────┐
  BamerEnv       │                                                                      │
  obs+info ────▶ │  账本层：探测账本(雷达+位姿) + 轨迹账本(option路径)                      │
  ◀───────────── │      │ 每个决策边界派生                                                │
  低层动作原语    │      ▼                                                               │
                 │  信念张量 (16,16,16) uint8 ──▶ Dueling 三分支网络                      │
                 │      │                        │ Explore score map / Pick / Deliver   │
                 │      │                        ▼ 掩码 + argmax(ε-greedy)             │
                 │      │                 高层动作 (option)                              │
                 │      │                        │                                     │
                 │      │                        ▼                                     │
                 │      └──────────────▶ 执行器：BFS 规划 + 每步重规划 + 不可达中止        │
                 └────────────────────────────────┬────────────────────────────────────┘
                                                  │ 展开为 {F,TL,TR,TB} 原语序列
                                                  ▼
                                              BamerEnv.step()
```

与论文（三模块框架）的对应：**建图模块 = 账本+信念派生**（替代 SLAM，无噪声、零漂移）；**决策模块 = 三分支网络**（Explore 即论文的决策模块，Pick/Deliver 为派送任务扩展）；**规划模块 = (格,朝向) BFS 执行器**（替代 A*+TEB，离散格世界无需连续控制）。

## 1. 问题形式化

### 1.1 半马尔可夫决策过程（SMDP）

高层策略只在 **option 边界**被调用：每个高层动作由执行器展开为多步原语序列，执行到终止条件（到达目标 / 不可达中止 / 任务事件）后交还控制权。option 执行期间策略不做决策（v1 = commit-until-done，不做中途打断）。

- 一次决策的最小时间粒度 = 一个 option（可能只含 1 步）
- 折扣：SMDP 贝尔曼算子，target 中用 **γ^τ**（τ = 该 option 实际步数）

### 1.2 马尔可夫性：信念张量即充分统计量

任务在信念张量上**严格马尔可夫**：未来代价与回报只依赖（信念、位姿、carrying、任务进度）。时序信息（GRU 类记忆）不是正确性必需，只是学习辅助——v1 用前馈网络 + 手工轨迹通道，GRU 留作开关预留（§4.4）。

### 1.3 探索的定位

探索是**手段不是目标**：全部 POI（2 台机器 + 2 个终点）定位即停止探索转入派送。奖励以任务完成为主信号（§5），不使用论文的地图熵主奖励（熵奖励会在 POI 找齐后继续驱赶机器人游走无价值区域，与主目标冲突；熵仅在搜索预训练臂 B 中作为阶段 0 目标，见 §6.2）。

## 2. 状态设计

### 2.1 输入张量：(16, 16, 16) uint8

| 组 | 通道 | 值域 | 语义 |
| --- | --- | --- | --- |
| 墙位信念 (4) | `wall_N/E/S/W` | 0/1/2 | 0=未探测，1=已探明无墙，2=有墙。每步从探测账本派生，**永不增量改写** |
| 位姿 (4) | `pose_N/E/S/W` | 0/1 | 机器人在 (x,y) 且朝向 d → 该通道在 (x,y) 处=1；四通道合起来唯一确定"我在哪+朝哪"（one-hot 融合：朝向是循环量且动作 TL/TR = ±1 mod 4，标量假序有害；并与墙位通道方向对齐，使"正前方有无墙"成为静态权重共享的卷积运算） |
| 状态机知识 (2) | `poi_quyuan`, `poi_zhaojun` | 0/1/2 | 0=未识别；1=已识别未送达（在该机已知格标 1）；2=已送达 |
| 终点知识 (2) | `poi_chuguo`, `poi_xihan` | 0/1 | 0=未定位；1=已定位（发现且识别后在该格标 1）。终点固定 (8,8)/(7,7) 但对机器鼠封闭，**须自主发现**——寻找终点是探索目标的一部分 |
| carrying (2) | `carry_quyuan`, `carry_zhaojun` | 0/1 | 正在背该机 → 全图广播 1；空手 = 双通道全 0（全局量用广播通道） |
| 轨迹 (2) | `trail_prev_option` | 0/1 | 上一个 option 实际走过的格子标 1（新近性上下文） |
| | `pose_prev_boundary` | 0/1 | 上一个决策边界时的机器鼠位置标 1（与当前位姿合成上次 option 位移向量） |

**四条编码约定**（全通道贯穿）：

1. **账本派生**：除账本外没有任何被维护的空间地图；信念张量在每个决策边界由 `f(探测账本, 轨迹账本, 事件, 位姿)` 一次性重建，无写入路径——共享墙镜像漏写等一致性 bug 在结构上不可能发生；
2. **全零 = 未知**：POI 未发现、空手 → 对应通道全 0，不编造数值（无噪声确定性仿真下墙存在概率无源，故三态类别编码而非概率编码——噪声出现时升级为 log-odds，张量形状不变）；
3. **类别量用小整数**：墙位 0/1/2、机器 0/1/2、终点 0/1（基数 ≤3 时标量与 one-hot 的表达力差距由深度补齐，假序无害；唯朝向因循环结构 + 通道复用而享受 one-hot）；
4. **全局量广播通道**：carrying 等非空间事实做成全图常量通道，等于给每个感受野注入统一特征。

**刻意不进 state**：步数计数（任务动态不依赖时间）、`delivery_map`（题目规则，硬编码执行器）、任何 GT 墙线/POI 真位置（R1）。识别标记的数据来源 = 分类器输出（M2.5 接口，当前 GT 直通占位），不是事件字段——换真识别模型时算法侧零改动。

### 2.2 账本层（信念的数据来源，R1 自洽）

| 账本 | 内容 | 数据来源（全部算法侧合法通道） |
| --- | --- | --- |
| 探测账本 | 规范形式感知掩码：`sensed_south[x][y]` / `sensed_west[x][y]`（与 maze.py 南/西墙约定同构） | 每帧雷达扫描（DDA 射线穿越的格边界=无墙已探明、命中边界=有墙已探明）+ 自身位姿复算；mask 只增不减 |
| 轨迹账本 | 各 option 的实际路径格序列 | 执行器自身规划并走过的路径（`env.visited_cells` 同源，自身信息合法） |

派生墙值：`值 = sensed ? (墙 ? 2 : 1) : 0`——**墙值永远不存储，只存"看过了什么"**。派生开销实测：循环版 107.7 µs/次（1024 次 bool 查询），训练全程外推 ~10 s，可忽略（基准：`tools/bench_belief_derive.py`）。

**规划语义（悲观约定）**：unknown 一律按不可通行处理——执行器只在"已知空闲格"上规划。探索推进机制 = 雷达视线揭示新的空闲格 → 已知可达集扩张 → 下一个 option 得以进入新揭示区域。量程 2.0 格 + 360° 扫描保证 frontier 处恒有已揭示的相邻可进格，规划不会被卡死。

## 3. 动作空间与执行器

### 3.1 高层动作（option）

| 高层动作 | 参数 | 参数来源 | 合法条件（掩码） | 终止条件 |
| --- | --- | --- | --- | --- |
| **Explore** | 目标点 (x,y) | 网络在全图 256 格上自由打分 | 目标格 = 已知空闲且从当前 (格,朝向) 可达（在信念图上 BFS 可达） | 到达目标格；途中目标彻底不可达 → **中止**（失败信号交还高层） |
| **Pick** | 状态机标签（2 选 1） | 网络选择；目标格 = 该机已识别位置 | 该机已识别 **且** 手上为空（单机负载已确认） | 到达该机所在格 → 拾取生效（carrying 更新，`Pickup` 事件） |
| **Deliver** | 无参数 | 目标格 = `delivery_map[手中机器]`（硬编码执行器） | 手上有机器 **且** 对应终点已定位 | 到达终点格 → 派送**自动**生效（`Arrived` 事件，无需显式放下动作） |

合法组合 = 256 + 2 + 1 = **259 个离散选项**。Deliver 的合法性条件引入时序约束：终点未定位前 Deliver 非法，策略被迫先完成足够探索。**无需终止动作**——选择 Pick/Deliver 而非 Explore 本身就是"停止探索"。

### 3.2 执行器（确定性规划层）

- **状态空间 (cell, heading)**：16×16×4 = **1024 态** BFS。⚠️ 转向计步（铁律 R4）后最短路不是格子 BFS——纯格子图搜出的路多转弯，直接吃掉步数指标；
- **每步重规划**：option 执行途中信念在更新（新墙揭示），已规划路径可能被新发现的墙堵死——每步在最新信念图上重规划（1024 态 BFS，微秒级）；
- **不可达中止**：目标彻底不可达 → option 以失败终止，控制权交还高层（失败信号本身是探索信息）；
- 执行器展开的低层动作全部落在 D5 原语 {F, TL, TR, TB} 上，碰撞语义随契约 §1（位置不变 + 计 1 步 + Collision 事件）。

## 4. 网络结构

### 4.1 架构：FCQN 三分支

```
输入 (16,16,16) uint8
   │
 共享卷积主干：3 层 3×3 conv，stride=1 pad=1，通道 32/64/64，ReLU
   │  ← 空间尺寸始终保持 16×16（score map 前提）
   ├──【Explore 分支】1×1 conv → A_explore (1,16,16)：逐格优势值
   ├──【池化分支】GAP → 向量 → 三个线性头：A_pick(2) / A_deliver(1) / V(s)(1)
   └──【辅助头，仅训练】1×1/反卷积 → 墙位补全 logits (4,16,16)
           CE 损失只在输入中 unknown 位置计算；GT 仅训练期监督（测试时头丢弃）
```

与论文的对应：**Explore ← 论文点动作的 score map 分支；Pick/Deliver ← 论文 terminal action 的池化分支（1 个输出推广为 3 个）**；辅助任务 ← 论文边缘分割 → **补全未知墙位**（墙即迷宫结构的全部载体，补墙 = 补全迷宫结构本身；GT 走与 RL reward 相同的通道——权重，防实例记忆靠多迷宫训练 + held-out 评估，见 §6/§7）。辅助头挂主干，与是否 GRU 无关。

### 4.2 合并与选择：dueling + 动态掩码

259 个优势值拼成联合向量（score map 256 + 池化分支 3），dueling 组合：

```
Q(s, o) = V(s) + A(s, o) − mean_legal(A)
```

- `mean_legal` = **只对合法动作取均值**——非法位置若先进均值会被 −∞ 污染，归一化全毁。次序：先在合法集合上算均值 → 再算各合法 Q → 非法动作不参加比较；
- 选择：ε-greedy / argmax 在合法动作上进行（ε 调度见 §6.2）。

### 4.3 拒绝的替代方案

- **flat FC 头**（拍平特征 → FC(259)）：参数多一个量级、丢平移共享，无补偿性好处；
- **标量朝向通道**：见 §2.1；
- **padded (2N+1)² 交错栅格**：动作合法性需掩码墙位/柱子、图像距离=2×迷宫步数、卷积效率低。

### 4.4 GRU 升级路径（开关预留）

`use_gru` 开关预留，本期 False。若启用：GRU 插在主干与头之间，时间步 = option 边界（非低层步）；"记忆长度 T"= BPTT 截断长度（隐状态跨 option 携带、episode 清零）；Explore score map 经**广播融合**（GRU 摘要复制为常量通道拼回主干特征图 → 1×1 conv 打分）；训练需序列化 replay + 段起点存隐状态。预期收益温和（信念已是记忆主体），价值由消融判定。

### 4.5 超参默认表【默认项，可调】

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 主干 | 3 层 conv，32/64/64，3×3 s1 p1 | 16×16 输入，空间尺寸不变 |
| 优化器 | Adam，lr = 1e-4 | 小网络稳定优先 |
| batch / target 同步 | 64 / 每 1000 个 option 更新 | 标准 DQN 件 |
| γ | 0.99 | SMDP 折扣 γ^τ |
| ε（option 级） | 0.10 → 0.02 线性退火，2 万 option | option 昂贵，探索噪声起点低于步级典型值 |
| replay buffer | 10 万条 option 转移，uint8 存储 | 单条 (16,16,16) uint8 = 4 KB；warmup 2000 option |
| Double-DQN | 开 | 确定性环境主要防过估 |
| 辅助头 λ | 0.5，消融 {0, 0.1, 0.5, 1.0} | λ=0 即对照组 |
| 轨迹通道 | 开（16 通道） | `use_traj_channels` 开关，消融 vs 14 通道 |
| use_gru | False | 本期前馈 |

## 5. 奖励设计

### 5.1 结构：时间代价主干 + 事件里程碑

主指标是"搜寻 + 派送"总步数（铁律 R3/R4），奖励主干即每步代价；里程碑给稀疏任务信号（事件钩子经 `info["events"]` 就绪）：

| 信号 | 数值 | 触发 |
| --- | --- | --- |
| 步代价 | **−1 / 步**（每个低层动作，含旋转与碰撞） | 每步 |
| 首次识别 | **+100** / 台（首次 `ImageFeed`） | 探索里程碑 |
| 终点发现 | **+100** / 个（首次发现并识别终点，`DestinationFeed`） | 探索里程碑 |
| 送达 | **+300** / 台（首次 `Arrived`） | 派送里程碑 |
| 碰撞 | **无额外惩罚**（模型一般不会撞墙，时间代价即惩罚） | `Collision` |
| 超时 | **无额外惩罚**（truncated 截断即可） | `Timeout` |

量级设计原则：里程碑 ≫ 步代价（一台全程派送 ≈ 数十步，+300 保证"绕路去送达"恒优于"放弃"）；识别×2 + 终点发现×2 + 送达×2 = +1000，典型 episode 总步数百级，回报信号区分度充足。**SMDP 折算**：option 的累计奖励 = Σ(−1) + 途中里程碑，高层转移按 γ^τ 折扣。

**明确不做**：地图熵主奖励（§1.3）；POI 位置预测辅助头（随机布点 = 可达格均匀采样，位置先验无信号；官方图上则是记忆）。

## 6. 训练协议

### 6.1 经验与学习件

- **转移格式（option 级）**：`(s_before, option, Σr, s_after, τ)`；s 为 16 通道 uint8 信念张量；
- 学习件：replay + target network + Double-DQN + 梯度裁剪；损失 = TD 均方误差 + λ·辅助 CE（共享主干两路反传）；
- 复现性：全部随机流（环境种子、雷达流、网络初始化、ε 采样）走统一种子管理；同种子两次训练曲线一致（确定性允许 GPU 非严格误差，需声明）。

### 6.2 训练课程：三臂消融

阶段 0 预训练（仅探索目标）→ 阶段 1 全任务微调的**课程式训练**设为三臂消融：

| 臂 | 阶段 0 目标 | 阶段 0 终止 | 说明 |
| --- | --- | --- | --- |
| **A 搜索预训练（主臂）** | −1/步 + 识别 +100 + 终点发现 +100（**去掉**送达 +300） | 4 个 POI 全部定位，或 max_steps | 即全任务的前半段，与阶段 1 探索子任务逐事件对齐，迁移最顺滑；env 加 `curriculum="search"` 开关（改 terminated 语义 + 关送达奖励） |
| **B 熵预训练** | −1/步 + 信息增益（未知墙位数，精确 bit 计数） | 步数预算 | 信号更稠密，但教"探索一切"，与任务最优的"探索到够用为止"有偏差 |
| **C 基线（原型）** | 无阶段 0，从头直接训全任务 | — | 对照基线 |

**阶段切换机制**（A/B → 阶段 1）：加载 checkpoint 权重；**replay buffer 清空**（阶段 0 的 transition 奖励语义失效，混用毒化 target）；target 网络重置；ε 从低值重启（0.05，策略已合理）；可选主干判别式降 lr。

**迁移预期**：主干特征与 Explore score map 的空间偏好迁移；Q 值尺度被重学（无害）；Pick/Deliver 头在阶段 0 因动作恒非法掩码而无梯度，带随机初始化进入阶段 1——在已"懂迷宫"的主干上从头学，正是设计意图。

**风险与对策**：切换点 Q 值震荡（评估曲线 V 形坑）为预期行为，非 bug；阶段 0 过长会把"穷尽式探索"烙进主干（负迁移/特征锁死）——**跑到探索指标收敛即停，宁短勿长**；三臂对比以最终报告数据说话。

**环境分工**：阶段 1 主力用 `randomize=True`（随机迷宫 + 随机布点，防实例记忆，也是辅助头 GT 监督的合法性前提）；最后阶段切官方 2022 赛图固定场景收敛。本地只跑分钟级冒烟（管线验证），正式训练脚本 + 说明交私人服务器执行。

## 7. 评估协议

### 7.1 指标

| 级别 | 指标 |
| --- | --- |
| **主指标** | 成功率 / 搜寻步数 / 派送步数 / 总步数（含转向，铁律 R4） |
| 参照上限 | **全知 BFS 参照**：已知全图下，枚举任务事件序（拾取/送达的合法排列，配对固定）取最短 (格,朝向) 路径总步数——策略步数与参照的差距是核心报告量 |
| 诊断量 | 探索区域率、墙知识率、option 数分布、识别时机 |

### 7.2 评估套件（防实例记忆）

- **held-out 随机套件**：从未参与训练的固定种子集（如 100 seeds）——泛化能力的干净实验场；
- **官方图套件**：2022 赛图固定场景——含记忆成分的实战成绩；
- 两套**分开报告**。全部消融在 held-out 上对比。

### 7.3 消融矩阵（最终报告的故事线）

## 8. 实现路线图（algo/ 模块与冒烟顺序）

```
algo/
├── belief.py     # 探测账本 + 轨迹账本 + 16 通道派生（只吃 obs/info，R1 自检单测）
├── actions.py    # 三动作定义 + 合法性掩码（259 选项枚举）
├── executor.py   # (cell,heading) 1024 态 BFS + 每步重规划 + 不可达中止
├── network.py    # 主干 + 三分支 dueling 头 + 辅助头（use_gru / use_traj 开关）
├── replay.py     # option 级 buffer（uint8）
├── agent.py      # ε-greedy + Double-DQN 学习步（γ^τ）
├── trainer.py    # 训练循环 / checkpoint / 种子管理 / 三臂课程配置
├── eval.py       # 固定 seed 套件 + 全知 BFS 参照 + 指标
└── configs/      # 一次实验一个 yaml（含课程臂选择）
```

冒烟顺序（每步可独立验证，前馈版本身即消融对照）：

1. `belief.py`：受控场景下派生张量与手算对拍 + R1 自检（构造不含 GT 的输入流跑通）；
2. `executor.py`：已知图最短路解析解对拍（含转向计步用例）；重规划/中止用例；
3. `network.py`：随机权重 + 手工构造信念场景（"空手全未识别" / "背屈原且终点已定位"）前向 + 掩码 + argmax 冒烟——肉眼核对选出的动作不违反掩码；
4. `agent.py + replay.py`：几十 option 训练，损失/回报曲线无 NaN、合法动作占比 100%；
5. `trainer.py + eval.py`：本地分钟级冒烟 → 服务器正式训练。
