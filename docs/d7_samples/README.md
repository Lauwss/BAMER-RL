## 三方案对比

| 维度 | A 原始点云 | B 局部占据栅格 | C 降采样极坐标向量 |
| --- | --- | --- | --- |
| 单帧维度 | 180×2（点）或 180（r-θ） | 7×7×3 值（窗内） | 24 维（扇区数可调） |
| 信息量 | 最高，可重建任意其他表示 | 中（窗内结构化） | 低（最小距离，有遮挡细节丢失） |
| 网络适配 | 需 PointNet 类/自定义结构 | 类似图像，CNN 友好 | MLP/全连接即插即用 |
| 与迷宫格子结构契合 | 弱 | **强**（格子语义与 BFS/规划天然对齐） | 中 |
| 多帧融合 | 需自建图逻辑 | **天然支持**（栅格累积 = 信念图） | 需自行设计记忆 |
| 超参 | 束数 | 窗大小 | 扇区数 |
| 展示效果（成果要求 3） | 直观 | 直观 | 一般 |
