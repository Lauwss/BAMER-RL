# A/C 臂探索塌缩：分析过程与修复（2026-11-21）

> 背景：2026-11-20 首次三臂正式训练（本机 RTX 4060，seed 0，各 160k options）。
> 臂 B（熵预训练）训练期 6 次送达成功；臂 A（搜索预训练）与臂 C（基线）全程
> 0 次成功、探索率坍缩、奖励恒为负。本文记录取证过程、根因结论、修复设计与
> 实验结果。修复代码已合入（`algo/trainer.py` `shape_potential`，默认关）。

## 1. 症状（训练曲线证据）

| 臂 | 训练期成功 | stage1 探索率 均值/峰值 | 末段 q_mean | td_loss 末段 |
|---|---|---|---|---|
| A 搜索预训练 | 0 / 453 eps | 11.4% / 27.3%（**末段降至 4.7%**） | −97.5 | 1.5–7.9（小而稳） |
| B 熵预训练 | **6 / 528 eps** | **17.3% / 40.2%** | −87.2 | 140–209（里程碑传播时尖峰） |
| C 基线 | 0 / 354 eps | 7.2% / 19.1%（末段 5.5%） | −94.1 | 1.5–2.8（小而稳） |

8-seed 贪心 held-out 评估（最终 checkpoint）：A 探索 1.07% / C 1.32% / B 7.81%，
三臂成功率均 0%。

关键观察：
- **q_mean ≈ −94～−97** 恰好是"每个 option 白付 ~步数成本、永无奖励"的折现价值
  （−1/步 × 平均 τ×γ^τ 累加），说明价值函数收敛到"悲观无望"的定点；
- **td_loss 小而稳（A/C）** → 不是数值发散（deadly triad），是干净地收敛到了
  错误（局部最优）的策略；B 的 td 尖峰恰是里程碑信号开始传播的特征；
- 探索率随训练**单调下降**（A：峰值 27.3% → 末段 4.7%）：策略越学越保守。

## 2. 取证过程（假设逐个检验）

### 2.1 里程碑（正奖励源）采样频率统计

`reward = −steps + bonus`（三臂奖励函数同构），从 episodes.csv 反解
`bonus = reward + steps`：

| 臂/阶段 | bonus>0 的 episode 占比 | bonus 总量 | 备注 |
|---|---|---|---|
| A stage0 | 11.5% | 1,400 | max +100（仅识别/终点，无送达） |
| A stage1 | 19.4% | 7,500 | max +200 |
| C full | **11.0%** | **4,400** | max +100 |
| B stage0 | 100%（按构造，信息增益即奖励） | 8,998 | — |
| B stage1 | **62.7%** | **91,900** | max +600（含送达 +300） |

**结论 1**：A/C 的正奖励源（识别 +100 / 终点 +100 / 送达 +300）在 80–89% 的
episode 里完全没被采样到；B 的探索预训练把 stage1 里程碑采样率拉到 62.7%，
正奖励总量是 A/C 的 **12–21 倍**。没有正信号 → TD target 只剩负步数成本 →
Q 收敛到悲观定点。

### 2.2 贪心 rollout 探针（最终 checkpoint，3 seeds）

载入 checkpoint 纯贪心跑 episode，记录所选 option 序列：

```
臂 A（3 seeds 全部同型）:
  唯一 option 数 = 3，重访率 = 1.00，1000 步超时
  动作序列: Explore(1,0) → Explore(2,0) → Explore(0,0) → 无限循环
臂 C（3 seeds 全部同型）:
  唯一 option 数 = 3，重访率 = 1.00，1000 步超时
  动作序列: Explore(1,0) → Explore(2,0) → Explore(0,0) → 无限循环
臂 B:
  唯一 option 数 = 5–19，重访率 0.94–0.99
  循环更大（距起点 8–10 格的区域），偶尔触发 DestinationFeed（发现终点）
```

**结论 2**：A/C 的贪心策略是**起点旁 3 个格子之间的确定性死循环**——259 个
选项里只选 3 个，每一步都重访已探索格，不产生任何新信息。B 的循环更大且在
移动途中持续扫描出新墙位（贪心评估探索率 7.81% vs 1.07%/1.32%）。

### 2.3 option 长度统计（episode 级 τ = steps/options）

| 臂/阶段 | 前半均值 | 后半均值 |
|---|---|---|
| A stage0 | 2.23 | 4.42 |
| C full | 1.85 | 3.11 |
| B stage1 | 3.55 | 6.44 |

**结论 3**：A/C 倾向选择**相邻格目标**（τ≈2，option 退化成单步移动）；B 的
option 更长（走向远处 frontier）。这与 2.2 的死循环互为印证。

### 2.4 排除的假设

- ~~数值发散/过估计~~：td_loss 小而稳，无发散迹象（§1）；
- ~~实现 bug（观测/掩码/账本泄漏或错位）~~：14/14 测试过 + 账本手算测试 +
  同种子复现一致；B 臂用同一套代码学到送达，排除系统性实现错误；
- ~~ε 太小~~：stage1 ε 全程 0.05（`begin_stage1` eps_override 钉死，日志可证），
  与 B 相同；B 在同 ε 下能逃逸，ε 不是分归因素；
- ~~γ^τ 折断远期信号~~：是次要因素（+100 里程碑在 τ=50 外折现 ×0.605，仍在），
  但前提是"先撞上里程碑"，主因不在此。

## 3. 根因（因果链）

1. **奖励结构没有给"获取信息"任何正梯度**。D8 奖励 = −1/步 + 稀疏里程碑；
   在 milestone 被采样到之前，所有 option 的即时奖励都是负的，且**互成比例
   于步数**——"选相邻格"永远严格优于"走向 frontier"（步数少）。
2. Q-learning 把这个梯度学到位：**全部收敛到"最短 option"偏好** → 在已知格
   里挑近的 → option 长度坍缩到 τ≈2 → 3 格死循环（贪心 argmax 在近似相等
   的 Q 值上确定性地选同一批目标；局部扫描饱和后信念不再变化，循环自我锁定）。
3. 死循环 → 不再获得新信息 → 里程碑永远采不到（80–89% episode bonus=0）→
   TD target 无正项 → Q 停在悲观定点。**因果闭环，自我强化**。
4. B 臂为什么没塌：stage0 奖励 = 信息增益（1 bit = 1 分）——dense 正信号直接
   奖励"让 unknown 变少"，策略学会走向 frontier 持续扫描；stage1（奖励换
   milestone）虽然 buffer 清空，但**策略已带探索先验**，ε=0.05 随机性足以让
   里程碑以 62.7% 的 episode 频率被采样 → 里程碑 TD 信号得以传播（td 尖峰
   140–209 即其特征）。
5. 次要放大器：合法掩码只允许 Explore 已知空闲格（悲观约定）——这本身正确
   （防不可达目标），但意味着"探索"只能靠**在 frontier 附近选目标 → 扫描
   揭示新边界**间接发生；没有信息奖励时，这个间接通道没有梯度。

一句话根因：**"−1/步 + 远期稀疏里程碑"在里程碑被采样前是一个反探索奖励；
A/C 在反探索梯度下收敛到最小移动循环，且循环结构阻止里程碑被采样，无法
自愈。B 的信息增益预训练恰好补上了缺失的探索梯度。**

## 4. 修复设计：势能拉势 shaping（policy-invariant）

### 4.1 选择依据

候选方案对比：

| 方案 | 改最优策略？ | 评价 |
|---|---|---|
| A. 势能拉势 F = γ^τ·Φ(s') − Φ(s)（Ng et al. 1999） | **不变** | 理论保证强；遥测和有界不可套利；实现小 |
| B. 臂 B 式信息增益直接加进主奖励 | 变 | 等于把 A/C 变成 B，消融意义丧失 |
| C. 前沿宏选项 / 掩码扩展 | 变（动作空间） | 契约 D6 层面变更，动作空间冻结，改动大 |
| D. 提高 ε | 不变 | 只增随机性不增方向性，B 的对照已证明不足 |

选 A：**在不动最优策略的前提下补探索梯度**——数学上只改变学习的速度路径，
不改变收敛点，与"契约冻结"的兼容性最好。

### 4.2 数学形式（SMDP 多步动作版）

对 option 边界转移 s →(o, τ步)→ s'：

```
F(s, o, s') = γ^τ · Φ(s') − Φ(s)      shaped_r = r + F
Φ(s) = 已知墙槽位数 / 2n²              （信息势，确定性派生自信念账本）
```

- 与 TD target 的 SMDP 折扣 γ^τ **同构**（Grzes 2017 多步动作 PBRS）→
  最优策略不变性成立；
- **terminated 时 Φ(s')=0**（定理严格条件；truncated 自举继续，保留 Φ(s')）；
- **不可套利**：每项 F 由 Φ∈[0,1] 与 γ^τ≤1 控制而有界；零增益 option 的
  F = Φ·(γ^τ−1) < 0——"反复进出已探索区"不但无益反而**每 option 额外付
  Φ·(1−γ^τ)·scale 的信息时间代价**，恰好惩罚死循环；正增益只能来自真实
  的新增墙位知识（Δunknown>0），无法凭空制造；
- `shape_scale = 2000`：全程拉势总量上限 2000 分（Φ 0→1），单 option 增益
  4 槽 ≈ +15 分（γ^τ≈0.97），是 −1/步量级的 ~7 倍但远小于里程碑 +100/+300，
  学习后期势饱和后自然交还里程碑主导。≈ 臂 B 每 bit 1 分量级的 2 倍
  （2000/512 ≈ 3.9/槽）。

### 4.3 实现（配置门控，默认关 = 冻结契约行为不变）

- `TrainConfig.shape_potential: bool = False`、`shape_scale: float = 2000.0`
  （`validate` 拒绝非法 scale）；
- `trainer._shape_reward(base, unknown_before, unknown_after, steps, terminated)`
  纯函数，主循环在 `reward_fn` 之后按门控叠加；
- 单测 `test_potential_shaping`：公式逐项（增益/零增益/terminated 两分支）、
  门控校验、端到端确定性；14/14 + 新测试全过；
- 同种子复现不受影响（shaping 是确定函数；默认关路径逐位不变）。

> **契约登记**：D8（奖励）冻结语义新增了"可选拉势项"。默认关闭时行为与冻结版
> 逐位一致；若 A/C 转正常后要把 shaping 转为正式配置，需按 §8 流程用户确认。

## 5. 修复实验结果（2026-11-21 重跑，seed 0，各 160k options）

重跑配置 = 原 yaml + `shape_potential=True`（运行时覆盖，out_dir 独立：
`algo/runs/armA_shaped` / `armC_shaped`，不动原塌存数据）。

### 5.1 训练期（主修复目标）

| run | 训练期送达次数 | stage1 探索率 均值（后半段） | 探索率峰值 | 墙知识峰值 |
|---|---|---|---|---|
| A 原始 | **0** | 11.4%（末段 **4.7%** ↓坍缩） | 27.3% | 38.7% |
| **A_shaped** | **14** | **18.0%（后半 19.2% ↑爬升）** | **40.2%** | **72.5%** |
| C 原始 | **0** | 7.2%（末段 5.5% ↓坍缩） | 19.1% | 34.0% |
| **C_shaped** | **6** | **14.1%（后半 14.6% ↑爬升）** | **35.2%** | **55.3%** |
| B（参照，熵预训练） | 6 | 17.3% | 40.2% | 63.1% |

- 探索率从"单调坍缩"变为"稳步爬升"，峰值追平/超过 B；
- **训练期送达从 0 → 14（A）/ 6（C）**，A_shaped 甚至超过 B 的 6 次——
  里程碑 TD 信号终于能被充分采样（因果闭环被打破的直接证据）。

### 5.2 贪心行为（rollout 探针，3 seeds + 8-seed held-out）

| run | 8-seed 成功率 | 8-seed 探索率 | 8-seed 墙知识 | 贪心唯一 option 数（3 seeds） |
|---|---|---|---|---|
| A 原始 | 0% | 1.07% | 3.61% | **3**（三格死循环） |
| **A_shaped** | 0% | **9.81%（9.2×）** | **20.36%（5.6×）** | 8–13 |
| C 原始 | 0% | 1.32% | 4.22% | **3**（三格死循环） |
| **C_shaped** | 0% | **5.71%（4.3×）** | **12.99%（3.1×）** | 4–9 |
| B 原始（参照） | 0% | 7.81% | 15.94% | 5–19 |

- **三格死循环被打破**：贪心路径先外推到距起点 8–10 格的 frontier 区域
  （(2,1)→(3,3)→(4,4)→…→(9,9) 型外扩），不再原地打转；
- A_shaped seed=757058591 贪心全程完成了一次 `ImageFeed→Pickup→Deliver→Arrived`
  完整任务环（该 seed 上贪心本身可送达单个机器）；
- 贪心 8-seed 成功率仍 0%——注意 **B 原始也是 0%**：这是任务期（milestone
  信用分配/交付精度）问题，不是探索问题；探索修复的目标已达成。

### 5.3 需要正确解读的两个数字

- **shaped run 的 episode 奖励绝对值更负**（−2000～−7000）：时间代价项
  Φ·(1−γ^τ)·scale 逐 option 累积所致（空转更亏、增益为正）。这是设计的
  一部分——修复改变的是 option 间的**微分信号**与学习收敛点，不是奖励
  绝对值的美观度；成功判据看探索率/送达次数/贪心评估，不看原始奖励值。
- **shaped run 的 q_mean 不可与原始 run 直接对比**（−324～−452 vs −87～−97）：
  Q 值现在定义在 shaped 奖励尺度上，含时间代价项的累积期望。

## 6. 结论与下一步

### 6.1 结论

1. **根因成立**：A/C 塌缩 = 反探索奖励（−1/步 + 未采样里程碑）下 Q 收敛到
   "最短 option"偏好 → 相邻格死循环 → 里程碑永不采样 → 无法自愈的因果闭环；
   B 不塌是因为信息增益预训练补上了缺失的探索梯度（62.7% vs 11–19% 的
   里程碑采样率差是 12–21 倍的信号差）。
2. **修复有效**：势能拉势 shaping（策略不变性保持）一次性解决三个症状——
   探索率坍缩（→爬升 2–3×）、训练期零送达（→14/6 次）、贪心死循环（→
   frontier 外扩 + 偶发完整任务环）；A_shaped 训练期表现已超 B 臂。
3. 修复以**默认关闭的配置项**合入（`shape_potential`），冻结契约行为逐位
   不变；转正需按 §8 流程确认。

### 6.2 下一步（按优先级）

1. **多种子确认**（服务器 3–5 seeds × 全臂）：本结论全部来自 seed 0 单跑；
   shaping 对 A/C 的增益量级需多种子稳健化；
2. **shaping 转正决策**（用户拍板项）：若转正，三臂配置加 `shape_potential: true`
   并固定 `shape_scale=2000`；
3. **任务期学习**（贪心成功率 0%，B 同样）：与探索无关——方向包括延长
   stage1、交付信用分配、C 臂 `eps_end` 0.02 vs stage1 0.05 的对齐（C 全程
   退火到 0.02，比 A/B 的 stage1 0.05 少了随机采样，是本轮未控制的差异）；
4. **可选增强**（均属契约变更，先拍板再做）：visited-cell 势叠加（贪心末段
   仍有 0.96–0.99 重访的大循环倾向）、前沿宏选项。
